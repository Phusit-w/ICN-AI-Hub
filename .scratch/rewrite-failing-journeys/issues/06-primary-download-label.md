# 06: ปุ่มหลักใต้ผลงานเป็น "ดาวน์โหลด Excel" แทน "ดาวน์โหลด"

**What to build:** เทสต์ 2 ข้อใน `artifact-actions` (หมวด "a multi-Agent Run") คาดว่าปุ่มหลักสีแบรนด์ชื่อ "ดาวน์โหลด" แต่แอปให้ "ดาวน์โหลด Excel" เพราะผลงานของ Run นั้นเป็นตาราง (ปุ่มเปลี่ยนชื่อเป็น "ดาวน์โหลด Excel" เมื่อผลงานเป็นตาราง ตามตั๋ว 01 ของ real-example-chats) ก่อนแก้เทสต์ให้ตรวจก่อนว่า Run ของ Agent ขายใบเสนอราคา (`agent-sales-proposal`) ควรได้ผลงานเป็นตารางจริงหรือเอกสาร ถ้าควรเป็นเอกสาร ให้ถือเป็นบั๊กของข้อมูลจำลองและแก้ที่ข้อมูล ถ้าควรเป็นตาราง ให้แก้เทสต์ให้ตรวจชื่อ "ดาวน์โหลด Excel" (หรือเลือก Run ที่ผลงานเป็นเอกสารแทน)

**Blocked by:** ไม่มี

**Status:** ready-for-agent

เทสต์ในตั๋วนี้ (2 ข้อ ใน `artifact-actions`):
- "ดาวน์โหลด" is the one primary button, and "บันทึกไว้ใช้ซ้ำ" is visible beside it
- saving for reuse keeps one primary button on the page

- [ ] ตัดสินและจดว่า Run ของ `agent-sales-proposal` ควรได้ผลงานชนิดไหน พร้อมเหตุผล
- [ ] เทสต์ทั้ง 2 ข้อผ่าน และยังยืนยันว่าหน้าเดียวมีปุ่มหลักสีแบรนด์ปุ่มเดียว
- [ ] `npx vitest run` ไม่มีข้อไหนล้มเพิ่ม
