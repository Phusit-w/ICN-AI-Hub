# 04: หน้า AI Agent ไม่มีแถวชิป "แสดงเฉพาะ" แล้ว

**What to build:** แบบ B เอาแถวชิปสองตัว ("ยอดนิยมในองค์กร", "แชร์ให้ฉัน") และกลุ่ม "แสดงเฉพาะ" ออก (ลบ `ShareFilterChips`) เหลือชิปตัวกรองตัวเดียวที่ปรากฏเมื่อเปิดหน้าด้วย `?filter=popular|shared` กดชิปเพื่อล้างตัวกรอง เทสต์ 2 ข้อยังหา group "แสดงเฉพาะ" ให้เขียนใหม่ให้ตรวจพฤติกรรมที่เหลือ: ลิงก์เก่า `/community` พาไป `/agents?filter=popular` แล้วชิปตัวกรองแสดงและกรองรายการ กดชิปแล้วล้างตัวกรอง

คำถามเปิดที่ผู้เขียนต้องดูก่อน: แบบ B ยังมีทางเปิดตัวกรอง "แชร์ให้ฉัน" จากหน้าได้ไหม ถ้าเป็นลิงก์อย่างเดียวแล้วไม่มีปุ่ม ให้จดเป็นข้อสังเกตในตั๋วนี้ ไม่ต้องแก้แอปในตั๋วนี้

**Blocked by:** ไม่มี

**Status:** done

เทสต์ในตั๋วนี้ (2 ข้อ ใน `shared-items`):
- the old community link lands on the Agents page with the "popular" filter on
- the Agents page has one row of the two chips, and the active one shows and filters

- [x] เทสต์ทั้ง 2 ข้อตรวจชิปตัวกรองที่มีอยู่จริง และผ่าน (ข้อที่ว่า "แถวเดียวสองชิป" เปลี่ยนชื่อและเนื้อหาให้ตรงกับของจริง)
- [x] จดข้อสังเกตเรื่องทางเปิดตัวกรอง "แชร์ให้ฉัน" ไว้ใต้ `## Comments`
- [x] `npx vitest run` ไม่มีข้อไหนล้มเพิ่ม

## Comments

- เทสต์ 2 ข้อเดิมถูกแทนด้วย 3 ข้อ: ลิงก์ `/community` แสดงชิป "ยอดนิยมในองค์กร", หน้า `/agents` เปล่าไม่มีชิป, `?filter=shared` กรองรายการและกดชิปแล้วล้างตัวกรอง
- ข้อสังเกต: ในแอปตอนนี้ไม่มีปุ่มหรือเมนูที่เปิดตัวกรอง "แชร์ให้ฉัน" หรือ "ยอดนิยมในองค์กร" เลย ทางเดียวคือลิงก์ `?filter=` (`/community` ที่เปลี่ยนทางไป popular และขั้นตอนใน Tour) ตัว "แชร์ให้ฉัน" จึงเปิดได้จาก URL เท่านั้น ไม่ได้แก้แอปในตั๋วนี้
