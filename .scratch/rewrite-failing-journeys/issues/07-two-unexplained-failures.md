# 07: เทสต์สองข้อที่ยังไม่รู้สาเหตุ

**What to build:** หาสาเหตุของเทสต์สองข้อนี้ก่อน แล้วแก้ที่ถูกจุด (แอปหรือเทสต์) ผมยังไม่ได้ไล่

1. `4-create-agent`: "@ calls an existing Agent to help write; the AI uses it, and it does not become a Step" ล้มเพราะหา link ชื่อ `/สร้างเองได้/` ไม่เจอ ดูว่าข้อความ "สร้างเองได้" ในหน้าสร้าง Agent หายไปหรือเปลี่ยนคำ
2. `workspace-chat-or-plan`: `"TOR" matches the Proposal Agent with Steps only as a word, not inside words like "inventory"` ล้มด้วย `expected false to be true` (ไม่ใช่เรื่องหาปุ่ม) ดูว่าตัวจับคีย์เวิร์ดของ planner เปลี่ยน หรือเทสต์ตั้งสมมติฐานเรื่องปุ่ม/ข้อความที่เปลี่ยนไป

## Comments

1. `4-create-agent` "@ calls an existing Agent": ล้มเพราะลิงก์ลัด "สร้างเองได้" บนหน้าแรกถูกเอาออกพร้อมแบบ B (ไม่มีที่ไหนในแอปใช้คำนี้แล้ว) สาเหตุคือเทสต์เก่า ไม่ใช่บั๊ก แก้ให้เริ่มที่ `/agents/new` เหมือนเทสต์ข้างเคียง งบคลิกจาก 3 เหลือ 2 (ให้ AI ช่วยเขียน + สร้าง Agent) เพราะลิงก์ลัดหายไป ทางจากหน้าแรกไปหน้าสร้างยังตรวจในเทสต์แรกของไฟล์ (AI Agent → สร้าง Agent)
2. `workspace-chat-or-plan` "TOR": **แอปถูกต้อง** ตัวจับคำใน `lib/runs.js` ใช้ `tor` อยู่แล้ว เทสต์ล้มเพราะอ่านชื่อ Agent จาก `aria-label` ของปุ่ม "ออกจากแผน" แต่ปุ่มนั้นตอนนี้ใช้ชื่อตามงาน (`ลบขั้นตอน <งาน> ออกจากแผน`) ไม่มีชื่อ Agent เทสต์จึงอ่านป้ายชื่อ Agent ในรายการแผน ("Sales Proposal" ซึ่งมีเฉพาะแผนของ Proposal Agent) และเช็กด้วยว่ามีแผนให้กด "เริ่มทำงาน" จริง ไม่มีบั๊กในแอป จึงไม่เปิดตั๋วแยก
