# 01: Agent ส่วนตัว คุยตั้งค่าครั้งแรก และหน้า "สิ่งที่ Agent รู้เกี่ยวกับคุณ"

**What to build:** ทุก User มี Agent ส่วนตัวหนึ่งตัว ตัวเลือก "อัตโนมัติ" ในเมนู Agent ของช่องสั่งงาน (`components/run/ComposerPick.jsx`) กลายเป็น Agent ส่วนตัว แสดงชื่อที่ผู้ใช้ตั้ง (เริ่มต้น "Agent ของคุณ") การ์ด Plan บอกว่า "Agent ของคุณวางแผนไว้ …" ตอนเข้าใช้ครั้งแรก Agent ส่วนตัวคุยตั้งค่าไม่เกิน 5 คำถาม (งานประจำ เครื่องมือที่ใช้ รูปแบบผลที่ชอบ) โดยเดาคำตอบจากแผนกและตำแหน่งของ persona ข้ามได้ ผลเก็บเป็นความจำ ผู้ใช้เปิดหน้า "สิ่งที่ Agent รู้เกี่ยวกับคุณ" อ่าน แก้ ลบทีละข้อ และเปลี่ยนชื่อ Agent ส่วนตัวได้ ความจำเห็นแค่เจ้าของ ไม่ติดไปกับ Agent ที่แชร์หรือถูกคัดลอก Run ที่ใช้ความจำแสดงใต้ผลงานว่า "ใช้ความจำ: …" เฉพาะข้อที่เกี่ยวกับงานนั้น และงานอ่อนไหวใช้โมเดลภายในเหมือนเดิม Agent ส่วนตัวไม่โผล่ในหน้าคลัง Agent
ต้องแก้เทสต์เดิมที่อ้าง "อัตโนมัติ" (เช่น `2-reuse`, `journey.jsx` helper `pickAgentFromMenu`) และ GLOSSARY ตรงกับของใหม่แล้ว
