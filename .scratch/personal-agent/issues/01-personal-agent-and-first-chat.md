# 01: Agent ส่วนตัว คุยตั้งค่าครั้งแรก และหน้า "สิ่งที่ Agent รู้เกี่ยวกับคุณ"

**What to build:** ทุก User มี Agent ส่วนตัวหนึ่งตัว ตัวเลือก "อัตโนมัติ" ในเมนู Agent ของช่องสั่งงาน (`components/run/ComposerPick.jsx`) กลายเป็น Agent ส่วนตัว แสดงชื่อที่ผู้ใช้ตั้ง (เริ่มต้น "Agent ของคุณ") การ์ด Plan บอกว่า "Agent ของคุณวางแผนไว้ …" ตอนเข้าใช้ครั้งแรก Agent ส่วนตัวคุยตั้งค่าไม่เกิน 5 คำถาม (งานประจำ เครื่องมือที่ใช้ รูปแบบผลที่ชอบ) โดยเดาคำตอบจากแผนกและตำแหน่งของ persona ข้ามได้ ผลเก็บเป็นความจำ ผู้ใช้เปิดหน้า "สิ่งที่ Agent รู้เกี่ยวกับคุณ" อ่าน แก้ ลบทีละข้อ และเปลี่ยนชื่อ Agent ส่วนตัวได้ ความจำเห็นแค่เจ้าของ ไม่ติดไปกับ Agent ที่แชร์หรือถูกคัดลอก Run ที่ใช้ความจำแสดงใต้ผลงานว่า "ใช้ความจำ: …" เฉพาะข้อที่เกี่ยวกับงานนั้น และงานอ่อนไหวใช้โมเดลภายในเหมือนเดิม Agent ส่วนตัวไม่โผล่ในหน้าคลัง Agent
ต้องแก้เทสต์เดิมที่อ้าง "อัตโนมัติ" (เช่น `2-reuse`, `journey.jsx` helper `pickAgentFromMenu`) และ GLOSSARY ตรงกับของใหม่แล้ว

## Comments

- สร้างแล้ว: `src/lib/personal.js` (ข้อมูลตั้งต้น ตัวช่วย ความจำที่เกี่ยวข้อง คำถามตั้งค่า), `state.personal` ใน store (เก็บตาม user id), หน้า `/agent` ("สิ่งที่ Agent รู้เกี่ยวกับคุณ") และ `/agent/setup` (คุยตั้งค่า 4 ข้อ), รายการ "Agent ของคุณ" ในเมนูโปรไฟล์ และบรรทัด "ใช้ความจำ: …" ใต้ผลงาน
- Agent ส่วนตัวไม่ใช่รายการใน `state.agents` จึงไม่โผล่ในหน้าคลังโดยธรรมชาติ ความจำอยู่ใน `state.personal` ไม่อยู่ในตัว Agent จึงไม่ติดไปกับ Agent ที่แชร์หรือบันทึกจาก Run
- User ทั่วไป (Somchai) ตั้งค่าเสร็จแล้วพร้อมความจำตัวอย่าง ส่วน Admin เป็นคนใหม่ (`setup: 'pending'`) เปลี่ยนไปมุมมอง Admin จะเห็นคำเชิญ "เริ่มตั้งค่า" ใต้ช่องสั่งงาน ข้ามได้ และคำเชิญไม่กลับมา "ตั้งค่าใหม่" จากหน้าความจำไม่ทำให้สถานะกลับเป็นรอ และการข้ามตอนตั้งค่าใหม่ไม่เปลี่ยนอะไร
- ความจำที่ใช้กับ Run: จับคู่คำสำคัญของแต่ละข้อกับคำสั่ง ใช้กับทุก Run ที่ส่งจากช่องสั่งงาน (รวมกรณีที่ผู้ใช้เลือก Agent เอง) ข้อที่ผู้ใช้เพิ่มเองไม่มีคำสำคัญ จึงยังไม่ถูกใช้ ถ้าต้องการให้ใช้ ต้องออกแบบวิธีจับคู่ข้อความอิสระเพิ่ม
- ข้อที่ว่า "งานอ่อนไหวไม่ใช้โมเดลภายนอก": พฤติกรรมเดิมของแอปไม่ได้เปลี่ยน เทสต์ในตั๋วนี้ตรวจแค่ว่างานอ่อนไหวยังขึ้นป้าย "พบข้อมูล…" ไม่ได้ตรวจชื่อโมเดล
- เทสต์เดิมที่ต้องแก้มีข้อเดียว (`2-reuse` ข้อเคลียร์ตัวเลือก ปุ่มเปลี่ยนชื่อเป็น "กลับไปใช้ Agent ของคุณ") ส่วน Schedule ยังอยู่บนตัว Agent รอตั๋ว 04
