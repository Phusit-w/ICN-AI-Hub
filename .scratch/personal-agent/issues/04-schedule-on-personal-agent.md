# 04: Schedule เป็นของ Agent ส่วนตัว

**What to build:** ย้ายกติกา Schedule จากตัว Agent (`agent.schedule`) ไปเป็นของ Agent ส่วนตัวของผู้ใช้ การ์ด Schedule ในแชต (`ScheduleCard` ใน `pages/Workspace.jsx`) แสดงว่าตั้งไว้ที่ Agent ส่วนตัว ไม่ใช่ลิงก์ไปหน้า Agent ในคลัง Schedule ที่ลงมือออกนอก (เช่นเพิ่มแถว Excel ทุกจันทร์) ใช้การตั้ง "ทำเองเลย" ของประเภทนั้นจากตั๋ว 03 ถ้าไม่ได้ตั้ง Run จะหยุดรอการกดยืนยัน ตัวอย่างแชต "บันทึกก้าวเดิน" ที่มีอยู่ต้องยังทำงานครบ แก้เทสต์เดิมที่คาดว่า Schedule อยู่ที่ตัว Agent

Spec: `.scratch/personal-agent/spec.md`

**Blocked by:** 03

**Status:** ready-for-agent (ทำส่วนที่ไม่ต้องรอตั๋ว 03 แล้ว เหลือข้อที่ 2 ซึ่งรอการ์ด "ถามก่อนลงมือ" และการตั้ง "ทำเองเลย" จากตั๋ว 03)

- [x] Journey: ตั้ง "ทุกวันจันทร์ 20:00" ในแชตแล้วการ์ด Schedule บอกว่าตั้งไว้ที่ Agent ส่วนตัว และ Agent ในคลังไม่มี Schedule
- [ ] Journey: Schedule ที่เพิ่มแถว Excel รอการกดยืนยันเมื่อไม่ได้ตั้ง "ทำเองเลย" และทำต่อเองเมื่อตั้งไว้
- [x] ตัวอย่างแชต "บันทึกก้าวเดิน" ยังทำงานครบและเทสต์ของมันผ่าน
- [x] `npx vitest run` ไม่มีข้อไหนล้มเพิ่ม

## Comments

- ทำก่อนตั๋ว 03 ตามที่เจ้าของโปรเจกต์สั่ง (ตั๋วนี้ระบุ Blocked by 03) จึงทำเฉพาะส่วนที่ไม่ต้องใช้ตั๋ว 03: Schedule ย้ายไปเป็นกติกาของ Agent ส่วนตัวแล้ว (`schedules` ใน `state.personal`, ตัวอย่างในข้อมูลตั้งต้นของ Somchai) `agent.schedule` หายจากข้อมูล Agent ทั้งหมด การ์ด Schedule ในแชตบอกว่า "ตั้งไว้ที่ Agent ของคุณ สำหรับงาน …" และลิงก์ไปหน้า `/agent` ซึ่งมีส่วน "ตั้งเวลา" แสดงรายการ หน้า Agent ในคลังไม่แสดงตั้งเวลาแล้ว
- ยังไม่ได้ทำ: ข้อที่ 2 (Schedule ที่เพิ่มแถว Excel หยุดรอการยืนยันเมื่อไม่ได้ตั้ง "ทำเองเลย") เพราะ "ทำเองเลย" และการ์ด "ถามก่อนลงมือ" อยู่ในตั๋ว 03 และแอปยังไม่มีการสร้าง Schedule ใหม่จากแชตจริง (เป็นเพียงตัวอย่างในข้อมูล) ทำต่อหลังตั๋ว 03
- เทสต์ที่แก้: `step-log-chat` (การ์ดและหน้า Agent) และเทสต์ความสอดคล้องของข้อมูล (`mock-data`) ให้ตรวจว่า Schedule เป็นของ Agent ส่วนตัวและไม่มี Agent ในคลังถือ Schedule
