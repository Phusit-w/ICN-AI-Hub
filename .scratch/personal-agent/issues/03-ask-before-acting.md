# 03: การ์ด "ถามก่อนลงมือ" สำหรับอีเมลและ Excel บน Office365 (จำลอง)

**What to build:** เพิ่มชนิดการลงมือออกนอก (Outward action) สามอย่าง: ส่งอีเมล, โพสต์ในกลุ่ม LINE, เพิ่มแถวใน Excel บน Office365 Agent ส่วนตัวร่างและอ่านเองได้ แต่การส่งหรือเขียนแสดงเป็นการ์ด "ถามก่อนลงมือ" ที่แสดงสิ่งที่จะทำ (เช่น ร่างอีเมลทั้งฉบับ หรือแถวที่จะเพิ่ม) ผู้ใช้กด "ส่ง"/"เพิ่ม" หรือ "ไม่ทำ" Excel เพิ่มแถวต่อท้ายอย่างเดียว ไม่ลบหรือเขียนทับ ผู้ใช้เปิด "ทำเองเลย" รายประเภทได้ในหน้า Agent ส่วนตัว และปิดกลับได้ ทุกการลงมือเข้าบันทึกการใช้ ดาวน์โหลด .xlsx จริงที่มีอยู่ไม่เปลี่ยน

- [x] `npx vitest run` ไม่มีข้อไหนล้มเพิ่ม

## Comments

- ประเภทการลงมือออกนอก: ส่งอีเมล, เพิ่มแถวใน Excel และโพสต์ในกลุ่ม LINE (ประเภทหลังนี้นิยามไว้ใน `src/lib/outward.js` และมีสวิตช์ "ทำเองเลย" แล้ว แต่ตัวการ์ดโพสต์จริงจะเกิดในตั๋ว 05 ซึ่งมี LINE)
- ตัวตรวจว่าคำสั่งไหนขอส่งอีเมล/เพิ่มแถว เป็นคำสำคัญแคบๆ (ร่าง/เขียน/ตอบ/ส่ง + อีเมล, เพิ่ม/ใส่/บันทึก + แถว/ลง Excel) เพื่อไม่ให้ชน "อีเมลใช้ไม่ได้" ซึ่งเป็นแจ้งปัญหา ไม่ใช่ขอร่างอีเมล คำสั่งแบบอื่นที่อยากให้จับต้องเพิ่มกฎ
- การ์ดอยู่ใต้ผลงานในแชต ขึ้นเมื่อ Run เสร็จ ถ้าตั้ง "ทำเองเลย" ไว้ การลงมือเกิดตอนการ์ดถูกแสดง (ไม่ใช่ตอน Run เสร็จขณะผู้ใช้อยู่หน้าอื่น) เป็นข้อจำกัดของเดโมจำลอง
- ไฟล์ Excel บน Office365 เป็นข้อมูลจำลองใน `state.office365` เพิ่มได้แต่ท้ายแถว ไม่มีการลบหรือเขียนทับ การลงมือทุกครั้ง (ยืนยัน ทำเอง ไม่ทำ) เข้า Audit log ที่หน้ากำกับดูแล
