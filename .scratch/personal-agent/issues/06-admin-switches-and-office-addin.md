# 06: สวิตช์ของ Admin และแผงจำลอง Office Add-in

**What to build:** หน้ากำกับดูแลมีส่วน "การเชื่อมต่อ": เปิด/ปิด LINE, อีเมล, Office365 และ Office Add-in ทั้งบริษัท (ปิดทั้งหมดตอนเริ่ม) ดูว่าใครเชื่อมแล้วกี่คน ตัดการเชื่อมของคนใดคนหนึ่งได้ และเข้าบันทึกการใช้ ปิดแอปแล้ว Channel และ Connection ของแอปนั้นหยุดสำหรับทุกคนทันที เมื่อบัญชีพนักงานถูกปิด ความจำและ Connection ของคนนั้นถูกลบ และเพิ่มแผงจำลอง Office Add-in: แผงด้านข้างแสดง Word, Excel, PowerPoint จำลองที่เปิดไฟล์ตัวอย่าง ผู้ใช้เลือกช่วงข้อมูลหรือย่อหน้าแล้วสั่ง Agent ส่วนตัว ผลใส่กลับเอกสารจำลอง ใช้สิทธิ์ของผู้ใช้ที่เปิดอยู่ ก่อนทำของจริงต้องตรวจเอกสาร Office Add-ins (โดเมน API, CORS, เวอร์ชัน Office) ตามที่บันทึกในสเปก

- [ ] Journey: ปิดบัญชีพนักงานแล้วความจำและ Connection ของคนนั้นหาย
