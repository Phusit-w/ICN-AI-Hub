# 06: สวิตช์ของ Admin และแผงจำลอง Office Add-in

**What to build:** หน้ากำกับดูแลมีส่วน "การเชื่อมต่อ": เปิด/ปิด LINE, อีเมล, Office365 และ Office Add-in ทั้งบริษัท (ปิดทั้งหมดตอนเริ่ม) ดูว่าใครเชื่อมแล้วกี่คน ตัดการเชื่อมของคนใดคนหนึ่งได้ และเข้าบันทึกการใช้ ปิดแอปแล้ว Channel และ Connection ของแอปนั้นหยุดสำหรับทุกคนทันที เมื่อบัญชีพนักงานถูกปิด ความจำและ Connection ของคนนั้นถูกลบ และเพิ่มแผงจำลอง Office Add-in: แผงด้านข้างแสดง Word, Excel, PowerPoint จำลองที่เปิดไฟล์ตัวอย่าง ผู้ใช้เลือกช่วงข้อมูลหรือย่อหน้าแล้วสั่ง Agent ส่วนตัว ผลใส่กลับเอกสารจำลอง ใช้สิทธิ์ของผู้ใช้ที่เปิดอยู่ ก่อนทำของจริงต้องตรวจเอกสาร Office Add-ins (โดเมน API, CORS, เวอร์ชัน Office) ตามที่บันทึกในสเปก

Spec: `.scratch/personal-agent/spec.md`

**Blocked by:** 03, 05

- [x] Journey: Admin ตัดการเชื่อมของคนหนึ่งแล้วคนนั้นต้องผูกใหม่ ส่วนคนอื่นไม่กระทบ
- [x] Journey: ปิดบัญชีพนักงานแล้วความจำและ Connection ของคนนั้นหาย
- [x] Journey: ในแผง Add-in จำลอง เลือกช่วงข้อมูลใน Excel จำลองแล้วสั่ง "สรุป" ผลใส่ลงเอกสารจำลอง และเมื่อ Admin ปิด Office Add-in แผงนี้ใช้ไม่ได้
- [x] `npx vitest run` ไม่มีข้อไหนล้มเพิ่ม

## Comments

- สวิตช์ 4 แอป (`src/lib/apps.js`, `state.apps`) ปิดทั้งหมดตอนเริ่ม แอปที่ปิดทำให้ LINE ไม่ตอบ, ไม่ร่างและไม่ทำการลงมือออกนอกของแอปนั้น (การ์ดที่ค้างแสดงว่า Admin ปิดอยู่), และแผง Add-in ใช้ไม่ได้ เทสต์ที่ต้องใช้แอปเปิดผ่าน `startJourney(route, { apps })`
- "ผูกแล้วกี่คน" และ "ตัดการเชื่อมรายคน" มีเฉพาะ LINE เพราะเป็นแอปเดียวที่ผูกรายบุคคล อีเมล/Office365 ในเดโมใช้สิทธิ์ผู้ใช้เองและไม่มีขั้นตอนเชื่อมต่อ
- ปิดบัญชี (`closeAccount`) ลบความจำ Agent ส่วนตัวและ LINE ของคนนั้น แต่เดโมไม่ได้กันไม่ให้บัญชีนั้นเข้าใช้
- แผง Add-in ที่ `/agent/addin` มีไฟล์ตัวอย่าง Word/Excel/PowerPoint และคำสั่ง "สรุป" คำตอบเป็นข้อความจำลอง ก่อนทำของจริงยังต้องตรวจเอกสาร Office Add-ins ตามสเปก
