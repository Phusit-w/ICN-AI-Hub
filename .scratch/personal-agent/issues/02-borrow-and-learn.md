# 02: รับ Agent ของคนอื่นมา และ Agent ส่วนตัวเสนอ "บันทึกไว้ใช้ซ้ำ"

**What to build:** Agent ส่วนตัวหยิบ Agent จากคลังมาใช้ได้ และผู้ใช้กด "รับไปใช้" เพื่อคัดลอกมาเป็นของตัวเอง (ใช้ `forkedFrom` ที่มีอยู่) ต้นฉบับมีเวอร์ชันใหม่แล้วขึ้นป้าย "มีเวอร์ชันใหม่" ให้กดอัปเดตเอง เจ้าของแก้ภายหลังไม่กระทบผลของผู้รับจนกว่าผู้รับจะกดอัปเดต เมื่อ Agent ส่วนตัวเห็นผู้ใช้ทำงานแบบเดิมซ้ำ (เช่น ขอสรุปเดิมสองครั้งขึ้นไป) จะเสนอ "บันทึกไว้ใช้ซ้ำ" ในแชต ผู้ใช้กดยอมรับ Agent ส่วนตัวไม่สร้างทักษะหรือขั้นตอนเองโดยไม่ถาม

## Comments

- "รับไปใช้" อยู่ที่หน้ารายละเอียด Agent ของคนอื่น (ไม่โผล่ที่ Agent ของตัวเอง) คัดลอกเป็นส่วนตัวของผู้รับ (`share: private`) และพาไปหน้าของสำเนา สำเนาจำต้นฉบับกับเวอร์ชันที่รับมา (`forkedFromId`, `forkedAtVersion`; ตรรกะอยู่ใน `src/lib/adopt.js`) ปุ่ม "คัดลอกไปปรับใช้" เดิม (เปิดฟอร์มให้ปรับก่อน) ยังอยู่
- "มีเวอร์ชันใหม่" ขึ้นที่หน้าสำเนาเมื่อเวอร์ชันของต้นฉบับต่างจากที่รับมา ปุ่ม "อัปเดตเป็น vX" เอาคำสั่ง ทักษะ ขั้นตอน ฯลฯ ของต้นฉบับมาทับ และเพิ่มบรรทัดในประวัติเวอร์ชันของสำเนา ก่อนกดผลไม่เปลี่ยน
- แอปยังไม่มีหน้าให้เจ้าของแก้ Agent (ตามสเปกเดิมที่เลื่อนไว้) เทสต์จึงจำลองการที่เจ้าของแก้ผ่าน store ด้วย `app.store` ที่เพิ่มในชุดทดสอบ (`test/journey.jsx`)
- "ขอเรื่องเดิมซ้ำ" หมายถึงคำสั่งเดิมเป๊ะ (ไม่สนช่องว่างและตัวพิมพ์) ที่เคยส่งมาก่อนโดยผู้ใช้คนเดียวกัน ยังไม่จับคำสั่งที่คล้ายกัน ถ้าต้องการต้องออกแบบวิธีวัดความคล้าย Agent ส่วนตัวแสดงบรรทัดแนะนำใต้ผลงาน ผู้ใช้กดปุ่ม "บันทึกไว้ใช้ซ้ำ" เดิมเพื่อยอมรับ ไม่กดก็ไม่มีอะไรถูกสร้าง และหลังบันทึกแล้วบรรทัดนั้นหายไป
- "Agent ส่วนตัวหยิบ Agent จากคลังมาใช้" ทำได้อยู่แล้วโดยตัวจับคู่คำสำคัญของ planner ไม่ได้เปลี่ยน
