# 05: LINE: หน้าจำลองแชต ผูกบัญชี คุยส่วนตัวและกลุ่ม

**What to build:** หน้าจำลองบอต LINE กลางของบริษัทในแอป (หน้าต่างแชตแบบโทรศัพท์ เปิดจากหน้า Agent ส่วนตัว) ผูกบัญชีด้วยรหัส 6 หลักที่แอปแสดง (หมดอายุเร็ว) ผู้ใช้พิมพ์ส่งหาบอต คนที่ยังไม่ผูกส่งข้อความมาแล้วบอตตอบวิธีผูก คุยส่วนตัว: บอตตอบด้วย Agent ส่วนตัวของคนที่ผูก ในกลุ่มจำลอง: ตอบเฉพาะเมื่อมี @ เรียก ประกาศตัวตอนเข้ากลุ่มครั้งแรกว่าอ่านเฉพาะข้อความที่เรียกมัน ไม่ใช้ความจำส่วนตัวในกลุ่มเว้นแต่ผู้ใช้เปิดให้เป็นครั้งๆ ข้อความที่ตัวตรวจข้อมูลอ่อนไหวจับได้ถูกปฏิเสธและบอกให้ใช้เว็บ เมื่อ Run เสร็จตอบสรุปสั้นกับลิงก์เข้าแอป ไม่ส่งไฟล์ ในกลุ่มตอบสรุปที่ไม่มีเนื้อหาลับ แจ้งเตือนเมื่อ Run เสร็จหรือ Schedule ทำงาน เปิด/ปิดได้ การโพสต์ในกลุ่มใช้การ์ด "ถามก่อนลงมือ" ของตั๋ว 03
