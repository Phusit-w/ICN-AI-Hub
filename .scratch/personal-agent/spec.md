# Spec: Agent ส่วนตัวของทุกคน + LINE, Office365 และ Office Add-in (เดโมจำลอง)

Status: ready-for-agent

ที่มา: grill กับเจ้าของโปรเจกต์ 2026-10-26 · ADR `docs/adr/0002-personal-agent-is-the-front-door.md` · ต่อจาก `docs/adr/0001-no-separate-workflow.md` · ศัพท์ใหม่ใน `GLOSSARY.md` (Personal agent, Memory, Connection, Channel, Outward action) · แบบ Hermes Agent: https://agentic-ai.readthedocs.io/en/latest/AgentPlatforms/hermes-agent/

## Problem Statement

พนักงาน ICN ส่วนใหญ่ไม่ถนัด AI การสร้าง Agent ให้ตรงงานตัวเองยังยากเกินไป และ Agent ที่คนเก่งในแผนกสร้างไว้ก็ไม่รู้ว่าคนอื่นควรใช้ตัวไหน ตัวเลือก "อัตโนมัติ" เลือกให้แต่ไม่รู้จักผู้ใช้ งานจริงของคนส่วนใหญ่ยังอยู่ใน LINE อีเมล และไฟล์ Word, Excel, PowerPoint ไม่ใช่ในเว็บแอปนี้

## Solution

ทุกคนมี **Agent ส่วนตัว** หนึ่งตัวเป็นทางเข้าหลัก (ADR-0002):

- ตั้งค่าครั้งแรกด้วยการคุยสั้นๆ (ไม่เกิน 4-5 คำถาม เดาจากแผนกก่อน ข้ามได้) แล้วเก็บเป็น **ความจำ** ที่ดูและแก้ได้ในหน้า "สิ่งที่ Agent รู้เกี่ยวกับคุณ"
- "อัตโนมัติ" ในช่องสั่งงานคือ Agent ส่วนตัว มันตัดสินเองว่าจะตอบเลย เสนอ Plan หรือเรียก Agent จากคลัง ตั้งชื่อได้ ชื่อเริ่มต้น "Agent ของคุณ"
- รับ Agent ของคนอื่นมา = คัดลอกเป็นของตัวเอง เห็นป้าย "มีเวอร์ชันใหม่" เมื่อเจ้าของแก้
- เรียนรู้เอง = จำข้อมูลผู้ใช้ + เสนอ "บันทึกไว้ใช้ซ้ำ" เมื่อเห็นงานซ้ำ (ผู้ใช้กดยอมรับ) ไม่สร้างทักษะหรือขั้นตอนเองโดยไม่ถาม
- ทางเข้านอกเว็บ (**Channel**): LINE (บอตกลางตัวเดียว คุยส่วนตัวหรือในกลุ่มเมื่อถูก @ เรียก) และ Office Add-in
- เชื่อมแอป (**Connection**): อีเมลและ Office365 (Excel บน OneDrive/SharePoint)
- การลงมือออกนอกต้องถามผู้ใช้ก่อนทุกครั้ง ผู้ใช้เปิดอัตโนมัติรายประเภทได้เอง
- Admin เปิด/ปิดแต่ละแอปและช่องทางทั้งบริษัท (ปิดทั้งหมดตอนเริ่ม)

**รอบนี้เป็นเดโมจำลอง** (ไม่ต่อ LINE, Microsoft 365 หรืออีเมลจริง) ออกแบบให้สลับเป็นของจริงได้ทีหลัง ยกเว้นดาวน์โหลด Excel ที่เป็นไฟล์จริงอยู่แล้ว

## Implementation Decisions

### Agent ส่วนตัว
- มีหนึ่งตัวต่อ User เป็นชนิดหนึ่งของ Agent (อยู่ใน `state.agents` ได้ แต่ไม่โผล่ในหน้าคลังและไม่ถูกแชร์) เจ้าของคือ User นั้น
- ตั้งค่าครั้งแรก: คุยในแชตใหม่ ก่อนถึงงานแรก ข้ามได้ ถามไม่เกิน 5 ข้อ ได้แก่ งานประจำ เครื่องมือที่ใช้ รูปแบบผลที่ชอบ ฯลฯ โดยเดาคำตอบเบื้องต้นจากแผนกและตำแหน่งของ persona
- "อัตโนมัติ" ในเมนู Agent ของช่องสั่งงาน = Agent ส่วนตัว (แสดงชื่อที่ผู้ใช้ตั้ง) ตัวเลือกอื่นในเมนูเหมือนเดิม
- ตัวตัดสินใจ chat/Plan และการเลือก Agent จากคำสั่ง (`lib/runs.js`) ทำงานเหมือนเดิม แต่ถือเป็นการตัดสินใจของ Agent ส่วนตัว และ Plan บอกว่า "Agent ของคุณวางแผนไว้ …"
- รับ Agent ของคนอื่น: คัดลอกเป็นของตัวเอง (ใช้ `forkedFrom` ที่มีอยู่) แสดง "มีเวอร์ชันใหม่" เมื่อต้นฉบับมีเวอร์ชันสูงกว่า และอัปเดตเมื่อกด
- ตัวสร้าง Agent ด้วยการคุยและ "บันทึกไว้ใช้ซ้ำ" คงเดิม

### ความจำ
- เก็บเป็นรายการสั้นๆ ที่ผู้ใช้อ่าน แก้ ลบได้ทีละข้อ ในหน้า "สิ่งที่ Agent รู้เกี่ยวกับคุณ"
- เห็นแค่เจ้าของ Admin เห็นเพียงว่าใครเปิดใช้และใช้เท่าไร (ผ่านบันทึกการใช้ที่มีอยู่) ไม่เห็นเนื้อหา
- ไม่ติดไปกับ Agent ที่แชร์หรือถูกคัดลอก
- Run ที่ใช้ความจำแสดงใต้ผลงานว่า "ใช้ความจำ: …" (เฉพาะข้อที่เกี่ยวกับงานนั้น) ไม่ส่งทั้งโปรไฟล์ งานที่ตัวตรวจข้อมูลอ่อนไหวจับได้ใช้โมเดลภายในเหมือนเดิม
- เมื่อบัญชีพนักงานถูกปิด ความจำและ Connection ของคนนั้นถูกลบ

### Channel: LINE (จำลองในแอป)
- บอตกลางตัวเดียวของบริษัท แสดงเป็นหน้าจำลองแบบหน้าต่างแชตโทรศัพท์ในแอป
- ผูกบัญชีด้วยรหัส 6 หลักครั้งเดียว (แอปแสดงรหัส ผู้ใช้พิมพ์ส่งหาบอต หมดอายุเร็ว) คนที่ยังไม่ผูกส่งข้อความมา บอตตอบวิธีผูก
- คุยส่วนตัว: บอตตอบด้วย Agent ส่วนตัวของคนที่ผูก เหมือนพิมพ์ในช่องสั่งงาน
- ในกลุ่ม: ตอบเฉพาะเมื่อถูก @ เรียก ไม่เก็บข้อความอื่นของกลุ่ม ตอนเข้ากลุ่มครั้งแรกประกาศว่าอ่านเฉพาะข้อความที่เรียกมัน ไม่ใช้ความจำส่วนตัวในกลุ่ม เว้นแต่ผู้ใช้เปิดให้เป็นครั้งๆ
- ข้อความที่ตัวตรวจข้อมูลอ่อนไหวจับได้ถูกปฏิเสธทาง LINE ให้ใช้เว็บแทน (ไม่เริ่ม Run)
- เมื่อ Run เสร็จ บอตตอบสรุปสั้นกับลิงก์เข้าแอป ไม่ส่งไฟล์ ในกลุ่มตอบสรุปที่ไม่มีเนื้อหาลับ ลิงก์เปิดได้เฉพาะคนที่ผูกบัญชี
- แจ้งเตือนทาง LINE เมื่อ Run เสร็จหรือ Schedule ทำงาน เปิด/ปิดได้เอง

### Connection: อีเมลและ Office365 (จำลอง)
- การ์ด "ถามก่อนลงมือ": ร่างอีเมลให้ตรวจแล้วกด "ส่ง" และ "เพิ่มแถวใน Excel" (ไฟล์บน Office365) ที่แสดงแถวที่จะเพิ่ม แล้วกด "เพิ่ม" เพิ่มแถวต่อท้ายอย่างเดียว ไม่ลบหรือเขียนทับ
- อ่านและร่างทำเองได้ ส่ง โพสต์ หรือเขียนต้องถามก่อน ผู้ใช้เปิด "ทำเองเลย" ได้รายประเภท (อีเมล, LINE กลุ่ม, Excel) และปิดกลับได้
- ดาวน์โหลด .xlsx จริงที่มีอยู่แล้วไม่เปลี่ยน

### Channel: Office Add-in (จำลอง)
- แผงด้านข้างในแอปแสดงแบบจำลองของ Word, Excel, PowerPoint ที่เปิดไฟล์ตัวอย่าง ผู้ใช้เลือกช่วงข้อมูลหรือย่อหน้าแล้วสั่ง Agent ส่วนตัว ผลใส่กลับเอกสารจำลอง
- ในของจริง Add-in ใช้สิทธิ์ของผู้ใช้ที่ล็อกอิน Office และอ่านเขียนได้เฉพาะไฟล์ที่เปิดอยู่ ก่อนทำของจริงต้องตรวจเอกสาร Office Add-ins เรื่องการประกาศโดเมน API CORS และเวอร์ชัน Office ที่รองรับ (ยังไม่ได้ตรวจ)

### Schedule
- กติกา Schedule ย้ายจากตัว Agent มาเป็นของ Agent ส่วนตัว (เพราะการเขียนออกนอกใช้สิทธิ์ของผู้ใช้) การ์ด Schedule ในแชตเดิมแสดงว่าเป็นของ Agent ส่วนตัว
- Schedule ที่เขียนออกนอก (เช่นเพิ่มแถว Excel ทุกจันทร์) ใช้การตั้ง "ทำเองเลย" ของประเภทนั้น ถ้าไม่ได้ตั้ง Run จะหยุดรอการกดยืนยัน

### Admin
- หน้ากำกับดูแลมีส่วน "การเชื่อมต่อ": เปิด/ปิด LINE, อีเมล, Office365, Office Add-in ทั้งบริษัท (ปิดทั้งหมดตอนเริ่ม) ดูว่าใครเชื่อมแล้วกี่คน ตัดการเชื่อมของคนใดคนหนึ่งได้ และทุกการกระทำเข้าบันทึกการใช้
- ปิดแอปแล้ว Channel และ Connection ของแอปนั้นหยุดสำหรับทุกคนทันที

## Testing Decisions

- ทดสอบเป็น journey ตามแบบที่มี (`test/journeys/*.test.jsx`, `startJourney`) ผ่านสิ่งที่ผู้ใช้เห็น ไม่ทดสอบโครงสร้างภายใน
- ทุกตั๋วจบเมื่อเทสต์ใหม่ผ่านและ `npx vitest run` ไม่มีข้อไหนล้มเพิ่ม (เทียบชื่อเทสต์ ไม่ใช่แค่จำนวน)
- ตั๋ว 01 และ 04 ต้องแก้เทสต์เดิมที่อ้างถึง "อัตโนมัติ" และการ์ด Schedule บนตัว Agent ให้ตรงกับของใหม่ ตามหลักว่าเทสต์ตามแอป
- ไม่มีชื่อพนักงาน ICN จริงในข้อมูลหรือเทสต์ ใช้ persona สมมติ

## Out of Scope

- การต่อ LINE Official Account, Microsoft 365, Graph API หรืออีเมลจริง
- การอ่านไฟล์ Excel ที่มีอยู่เป็นข้อมูลนำเข้า และการแก้หรือเขียนทับเซลล์ (รอบนี้ "เพิ่มแถว" อย่างเดียว)
- บอตที่อ่านทุกข้อความในกลุ่ม และการรับไฟล์รูปจาก LINE เข้า Run
- Agent ที่สร้างทักษะหรือขั้นตอนเองโดยไม่ถาม
- ปรับตัวสร้าง Agent ให้ทำผ่าน Agent ส่วนตัว (คงตัวสร้างเดิม)
- แก้ Agent ที่คัดลอกมาแล้วให้ผสานกับเวอร์ชันใหม่ของต้นฉบับ (มีแค่ "อัปเดต" ทับ)

## Further Notes

- GLOSSARY เขียนล่วงหน้าให้ตรงการตัดสินใจนี้ ระหว่างที่ตั๋ว 01 และ 04 ยังไม่เสร็จ คำว่า "อัตโนมัติ" และ Schedule บน Agent ในโค้ดจะยังไม่ตรงกับ GLOSSARY
- คำตอบของ Hermes Agent ในหัวข้อสิทธิ์: แหล่งที่ค้นเตือนว่า Agent แบบนี้ขอสิทธิ์กว้าง จึงตั้งให้ถามก่อนลงมือเป็นค่าเริ่มต้น
