# 01: แชตตรวจ SOC ครบทาง (ตาราง Artifact + ดาวน์โหลด Excel)

**What to build:** ใน User เดโม เปิด Thread "ตรวจ SOC เทียบ datasheet" จากประวัติแชตแล้วเห็นไฟล์ SOC กับ datasheet ที่แนบ สรุปจำนวนผ่าน/ไม่ผ่าน/ไม่พบ และตารางผลตรวจในพื้นที่ทำงาน คอลัมน์ ข้อ | ข้อกำหนดใน SOC | ค่าที่พบใน datasheet | หน้าที่อ้าง | ผล | หมายเหตุ ผลมี 3 ค่า คือ ผ่าน / ไม่ผ่าน / ไม่พบ ต้องตรวจเอง (มีครบทั้งสามในตัวอย่าง) กด "ดาวน์โหลด Excel" แล้วได้ไฟล์ .xlsx จริงที่คอลัมน์และแถวตรงกับที่แสดง ภาษาไทยอ่านได้ถูกต้อง มี Agent "ตรวจ SOC" (Agent ตัวเดียว ของ User สมมติ แชร์ในแผนกที่เหมาะ) ในคลัง Agent ตั๋วนี้วางชนิด Artifact แบบตาราง (หลายแท็บ, มีเครื่องหมายต่อแถว, มีหมายเหตุ) ที่ตั๋วอื่นใช้ต่อ ข้อมูลทั้งหมดเป็นข้อมูลสมมติ
