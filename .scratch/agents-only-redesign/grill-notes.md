# Grill notes: หน้าแบบ Qwen + ผู้ช่วย AI อย่างเดียว

Status: needs-info (grill ยังไม่จบ)

## ตกลงแล้ว

- ไม่มี Workflow (สายงาน) แยก: งานหลายขั้นคือ Agent ที่มี Steps (ดู `docs/adr/0001-no-separate-workflow.md`, `GLOSSARY.md`)
- Step = ส่งงานให้ Agent อีกตัว ทำตามลำดับ รับผลงานจากขั้นก่อน
- Skill คงไว้เป็นส่วนประกอบที่เลือกในหน้าแก้ไข Agent ไม่มีเมนูหรือ tab ของตัวเอง
- "บันทึกไว้ใช้ซ้ำ" ได้ Agent เสมอ; Plan หลายผู้ช่วย → Agent ที่มี Steps
- แก้ไข Steps ท้ายฟอร์มสร้าง/แก้ไข Agent ("＋ เพิ่มขั้นตอน" ค่าเริ่มต้นว่าง) ย้ายตัวแก้ไขจาก `WorkflowBuilder` มาไว้ตรงนี้
- การ์ด Agent ที่มี Steps เหมือนการ์ดปกติ เพิ่มป้าย "N ขั้นตอน"
- เมนูซ้าย: แชตใหม่ · ค้นหา · ผู้ช่วย AI · ประวัติแชต (· ภาพรวมฯ สำหรับ Admin)
- จาก Qwen เอาแค่ช่องพิมพ์ทรงแคปซูล + ปุ่มไมค์พูดเป็นข้อความ (Web Speech API, ซ่อนถ้าเบราว์เซอร์ไม่รองรับ); ไม่เอาธีมมืด, Projects, ตัวเลือกโมเดล, โหมดคุยเสียง; คงแถว "ใช้ซ้ำ"
- ข้อสรุปนี้ใช้แทน `docs/Workspace-Redesign-Implementation-Prompt.txt` ในส่วนที่ขัดกัน (แถบซ้าย, คำว่า "สายงาน"); ส่วนการไหลในหน้าเดียว Request → Plan → AI Working → Result ยังใช้ได้

- Agent ที่เป็นขั้นตอนได้ต้องไม่มี Steps ของตัวเอง (1 ชั้น)
- Agent ในขั้นตอนถูกแก้ → ใช้เวอร์ชันล่าสุดเสมอ; ถูกลบ → เตือนก่อนลบพร้อมรายชื่อผู้ช่วยที่ใช้อยู่ ลบแล้วผู้ช่วยนั้นใช้งานไม่ได้จนกว่าเจ้าของจะแก้
- แชร์ Agent ที่มี Steps → แชร์ Agent ในขั้นตอนไปด้วยทั้งชุด; คำขอแชร์ทั้งบริษัทอนุมัติเป็นชุด
- Feedback นับให้ Agent ที่ผู้ใช้เรียกใช้เท่านั้น
- Workflow ใน mock data → Agent ที่มี Steps ชื่อเดิม; `/workflows` → หน้าผู้ช่วย AI; ประวัติงานเดิมเป็นงานของ Agent ใหม่
- ผู้ช่วยร่วมงานกันได้ 2 ทางเท่านั้น: Steps (บันทึกไว้) และ Plan (ระบบเสนอ) ไม่มีแบบคุยกันอิสระ
- หน้าสร้างผู้ช่วยแบบ GPT Builder: ซ้ายแชตกับ AI, ขวาฟอร์มที่ AI กรอกให้ (แก้เองได้) + ปุ่ม "✨ ให้ AI ช่วยเขียน" ที่ช่องคำสั่ง; ใช้แทนช่องบรรยายเดิม, wizard 6 หน้าคงไว้
- ในแชตสร้างผู้ช่วย พิมพ์ @ เรียกผู้ช่วยที่มีอยู่มาช่วยเขียนได้
- การเชื่อมต่อภายนอก (บอท LINE, Excel, งานที่เริ่มเองตามข้อความ/เวลา) แยกเป็น grill/spec ถัดไป

## ขั้นต่อไป

Grill ครบแล้ว (Q22–Q25 ตามที่แนะนำ):
- Plan ที่มี Agent ที่มี Steps → แตก Steps ของ Agent นั้นออกมาเป็นขั้นใน Plan ให้เป็นชั้นเดียวเสมอ
- แชตในหน้าสร้างผู้ช่วยไม่เข้าประวัติแชต; ออกก่อนบันทึก → ถามยืนยันก่อนทิ้งร่าง
- @ เรียกได้เฉพาะผู้ช่วยที่ผู้ใช้มีสิทธิ์ใช้; ผู้ช่วยที่ถูกเรียกมาช่วยเขียนไม่ถูกใส่เป็นขั้นตอนอัตโนมัติ
- ไม่มีเมนู "สร้าง" บนแถบซ้าย; สร้างผ่านปุ่ม "＋ สร้างผู้ช่วย" ในหน้าผู้ช่วย AI หรือ "บันทึกไว้ใช้ซ้ำ"
