# 02: เวิร์กโฟลว์กลายเป็นผู้ช่วยที่มีขั้นตอน

**What to build:** ผู้ใช้เจอแค่ **ผู้ช่วย AI** เวิร์กโฟลว์ในข้อมูลตัวอย่างกลายเป็นผู้ช่วยที่มี **ขั้นตอน** (Step) ชื่อเดิม ผู้ช่วยเหล่านี้อยู่ในแถว "ใช้ซ้ำ" ตัวเลือกผู้ช่วยในช่องพิมพ์ การค้นหา และหน้าผู้ช่วย AI การ์ดเหมือนผู้ช่วยทั่วไปแต่มีป้าย "N ขั้นตอน" เลือกผู้ช่วยที่มีขั้นตอนแล้วส่ง งานเริ่มทันทีโดยไม่ต้องยืนยัน Plan และใน Workspace เห็นแต่ละขั้นทำงานตามลำดับ แต่ละขั้นรับผลงานจากขั้นก่อน Review ที่มาหลัง Research ยังส่งงานกลับได้ 1 ครั้งเหมือนเดิม เมื่อระบบเสนอ Plan ที่มีผู้ช่วยที่มีขั้นตอน Plan จะแตกขั้นตอนของผู้ช่วยนั้นออกมาให้เห็นเป็นชั้นเดียว Feedback นับให้ผู้ช่วยที่ผู้ใช้เลือก งานเก่าที่เคยใช้เวิร์กโฟลว์แสดงเป็นงานของผู้ช่วยตัวใหม่ แถบซ้ายไม่มี "สายงาน" `/workflows` พาไปหน้าผู้ช่วย AI หน้าเวิร์กโฟลว์และตัวแก้ไขเวิร์กโฟลว์ถูกลบ ภาพรวมของ Admin นับผู้ช่วยที่มีขั้นตอนด้วย

การแปลงข้อมูล: โหนดผู้ช่วยตามลำดับเส้นเดินหน้า → ขั้นตอน; โหนดทักษะ → ทักษะของผู้ช่วยใหม่; โหนด trigger/condition/output และเส้นวนกลับ → ตัดออก คำขอแชร์ทั้งบริษัท Favourite และงานเก่าที่ชี้ไปที่เวิร์กโฟลว์ ชี้ไปที่ผู้ช่วยใหม่ ดู ADR `docs/adr/0001-no-separate-workflow.md` และ `GLOSSARY.md`
