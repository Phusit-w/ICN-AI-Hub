# 03: บันทึกไว้ใช้ซ้ำได้ผู้ช่วยที่มีขั้นตอน

**What to build:** หลังงานที่ผู้ช่วยหลายตัวทำตาม Plan ผู้ใช้กด "บันทึกไว้ใช้ซ้ำ" แล้วได้ผู้ช่วยตัวใหม่ 1 ตัวที่มีขั้นตอนเป็นผู้ช่วยใน Plan ตามลำดับ ผู้ช่วยใหม่ปรากฏในแถว "ใช้ซ้ำ" และหน้าผู้ช่วย AI พร้อมป้าย "N ขั้นตอน" และใช้งานได้ทันที หลังงานที่ผู้ช่วยตัวเดียวทำ ยังบันทึกเป็นผู้ช่วยแบบเดิม ไม่มีทางเลือก "บันทึกเป็นเวิร์กโฟลว์" อีก ขั้นตอนเป็นชั้นเดียวเสมอ เพราะ Plan แตกขั้นตอนไว้แล้ว
