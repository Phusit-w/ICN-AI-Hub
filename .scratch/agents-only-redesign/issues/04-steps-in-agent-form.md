# 04: ส่วน "ขั้นตอน" ในฟอร์มสร้างผู้ช่วย

**What to build:** ท้ายฟอร์มสร้างผู้ช่วยมีส่วน **ขั้นตอน** ค่าเริ่มต้นว่าง กด "＋ เพิ่มขั้นตอน" แล้วเลือกผู้ช่วยตัวอื่นเป็นขั้นตอน เรียงลำดับใหม่และลบขั้นตอนได้ ตัวเลือกแสดงเฉพาะผู้ช่วยที่ไม่มีขั้นตอนของตัวเอง สร้างผู้ช่วยแล้วจะได้ผู้ช่วยที่มีขั้นตอนตามที่เลือก และใช้งานได้ทันที รอบนี้ยังไม่ทำการแก้ไขผู้ช่วยที่มีอยู่แล้ว (เลื่อนไปหลัง demo)

Spec: `.scratch/agents-only-redesign/spec.md` (stories 13–16)
