# Agent ตัวอย่างตามแผนก (ฉบับร่าง)

> ร่างเพื่อใช้เสนอและนำร่อง — ปรับได้หลังได้คำตอบจากแต่ละแผนก
> อ้างอิงผังองค์กร มีผล 17 ส.ค. 2569 (`DataExam/icn organization chart 2025-2026_17aug26_signed.pdf`)

**วิธีอ่าน**
- **โมเดล**: 🔒 Local = ข้อมูลลับ ไม่ออกนอกบริษัท · ☁️ Cloud = งานทั่วไปที่ต้องการความฉลาดสูง (ส่งผ่าน gateway, จ่ายตามใช้)
- **ความรู้ที่ต้องใส่**: เอกสารที่ Champion ของแผนกอัปโหลดครั้งเดียว ผู้ใช้คนอื่นไม่ต้องทำอะไร
- **ผู้ใช้พิมพ์**: ตัวอย่างคำสั่งที่คนทั่วไปพิมพ์จริง — ไม่ต้องรู้เรื่อง prompt

---

## ทุกแผนก (Agent กลาง)

| Agent | ผู้ใช้พิมพ์ / แนบ | ได้อะไร | โมเดล |
|---|---|---|---|
| **สรุปเอกสาร** | แนบ PDF/Word + "สรุป 1 หน้า" | สรุปหัวข้อหลัก, ตัวเลขสำคัญ, สิ่งที่ต้องทำ | 🔒 |
| **แปลไทย ⇄ อังกฤษ** | วางข้อความ / แนบไฟล์ | ไฟล์แปลรูปแบบเดิม ใช้ศัพท์เทคนิคตามคลังคำศัพท์บริษัท | 🔒 |
| **ร่างอีเมล / หนังสือ** | "ร่างหนังสือขอเลื่อนส่งมอบงาน 2 สัปดาห์ ถึงลูกค้า X" | อีเมลหรือหนังสือตาม Template บริษัท (Word) | 🔒 |
| **ข้อความเป็นตาราง Excel** | วางข้อความ/ภาพตาราง + "ทำเป็น Excel" | ไฟล์ .xlsx พร้อมสูตรรวม | 🔒 |
| **ถามระเบียบบริษัท** | "ลาพักร้อนต้องแจ้งล่วงหน้ากี่วัน" | คำตอบพร้อมอ้างอิงเลขข้อในระเบียบ | 🔒 |

ความรู้ที่ต้องใส่: Template หัวจดหมาย/อีเมล, คู่มือพนักงาน, ระเบียบบริษัท, คลังคำศัพท์เทคนิค

## Operation — Project Implementation (~15 คน)

| Agent | ผู้ใช้พิมพ์ / แนบ | ได้อะไร | โมเดล |
|---|---|---|---|
| **สรุปประชุมโครงการ** | แนบบันทึกหรือไฟล์เสียงประชุม | รายงานการประชุม + ตาราง action items (ใคร / ทำอะไร / เมื่อไร) | 🔒 |

| **รายงานรูปหน้างาน** | แนบรูปถ่ายหน้างาน 20 รูป | รายงานภาพพร้อมคำบรรยายแต่ละรูป จัดหน้าเรียบร้อย | 🔒 |

ความรู้ที่ต้องใส่: Template รายงานความคืบหน้า/ส่งมอบ/รายงานการประชุม, สัญญาและ BOQ ของแต่ละโครงการ

**Workflow ตัวอย่าง**: สรุปประชุม → รายงานความคืบหน้า → ร่างอีเมลส่งลูกค้า

## ลำดับการนำร่องที่แนะนำ

1. **เฟส 1 (เดือนที่ 1)**: Agent กลาง + Project Implementation + Bid Prep — ครอบคลุม ~1 ใน 3 ของบริษัท
2. **เฟส 2**: Maintenance & Operations + Finance & Accounting
3. **เฟส 3**: Sales & Marketing, HR/Procurement, CEO's Office, Audit

**ตัวชี้วัดที่เก็บ**: จำนวนครั้งที่ใช้แต่ละ Agent, ชั่วโมงที่ประหยัด (ถามผู้ใช้หลังได้ผลงาน "ปกติงานนี้ใช้เวลากี่นาที"), จำนวน Agent ที่ Champion สร้างเพิ่ม

## สิ่งที่ต้องยืนยันกับแต่ละแผนก

- งานไหนทำซ้ำบ่อยที่สุด / เสียเวลาที่สุด
- มี Template เอกสารอะไรบ้าง
- เอกสารไหนห้ามออกนอกบริษัท
- ใครเป็น AI Champion
