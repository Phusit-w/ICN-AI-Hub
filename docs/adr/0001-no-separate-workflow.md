# A multi-stage job is an Agent with Steps, not a separate Workflow

ICN AI Hub used to have two things a User could build and reuse: an Agent (one assistant) and a Workflow (สายงาน, a saved chain of Agents). Most staff are not AI-savvy, and the Thai word สายงาน also reads as "department line", so we fold Workflows into Agents: an Agent may carry ordered Steps, Save for reuse always produces an Agent, and there is no Workflows page. This follows ChatGPT GPTs, Gemini Gems and Claude Projects, where users meet a single concept of a custom assistant.

## Consequences

- Skills stay as ingredients picked while building an Agent, with no page or tab of their own.
- Existing Workflows in the mock data become Agents with Steps.
